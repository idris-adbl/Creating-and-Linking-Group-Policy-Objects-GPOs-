# Creating-and-Linking-Group-Policy-Objects-(GPO)

  **Objective: Create and link policies to OUs**

1. On a Windows Server machine, click Windows icon > under Windows Administrator tools 
2. Open up Group Policy Management
3. We don’t do details of each GPO. For now, we will create a GPO on Group Policy Objects under mydomain.local 
4. Right click on Group Policy Objects > new> we name it as Mapped drives. 
5. Before we apply the mapped drive, we have to make sure that we have drives to map. On the C drive of Windows Server.
